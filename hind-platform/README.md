# منصة مس هند — الدراسات الاجتماعية

منصة تعليمية بالعربية (RTL) لمدرّسة الدراسات الاجتماعية **مس هند** للمرحلة الإعدادية: كورسات، محاضرات، اختبارات إلكترونية، حسابات طلاب وأكواد اشتراك.
مبنية على نفس هيكل منصة المرجع (خادم Node بلا إطار عمل + صفحات ثابتة)، بهوية بصرية جديدة (عنابي وذهبي) ومحتوى خاص بالمادة.

> **الصور والمحتوى الحالي تجريبي:** صورة المدرّسة رسم مؤقت (`public/assets/hind-*.svg`)، وروابط الفيديو في `data/lectures.json` تجريبية (`PLACEHOLDER`)، وأرقام التواصل أرقام وهمية.

## التشغيل
```bash
npm install
npm start        # http://127.0.0.1:4173
npm test         # فحص الدخان
```

## حساب تجريبي
| الحقل | القيمة |
|---|---|
| الهاتف | `01000000000` |
| كلمة المرور | `246810` |
| الصف | الثالث الإعدادي (مشترك في «تاريخ مصر الحديث والمعاصر») |

## أكواد التفعيل
| الكود | الكورس |
|---|---|
| `HIND-GEO1` | جغرافيا مصر والخرائط — أولى إعدادي |
| `HIND-HIS2` | التاريخ الإسلامي: من الفتح إلى المماليك — ثانية إعدادي |
| `HIND-GEO2` | جغرافيا أفريقيا والوطن العربي — ثانية إعدادي |
| `HIND-HIS3` | تاريخ مصر الحديث والمعاصر — ثالثة إعدادي |
| `HIND-GEO3` | جغرافيا السكان والموارد في مصر — ثالثة إعدادي |
| `HIND-CENTER-1` / `HIND-CENTER-2` | دخول «طالب سنتر» تجريبي |

الكورسان المجانيان: «تاريخ مصر القديمة» و«مراجعة نهائية».

## كيف تعدّل المحتوى
| ما تريد تغييره | الملف |
|---|---|
| الكورسات والدروس وروابط فيديو الدروس (`segments`) وملفات PDF | `data/courses.json` |
| المحاضرات المجانية (ضع رابط يوتيوب حقيقي في `url`) | `data/lectures.json` |
| الاختبارات (`quizzes-index.json` للفهرس، `quizzes-full.json` للأسئلة) | `data/` |
| أكواد التفعيل وأكواد السنتر | `lib/app.js` (`ENROLL_CODES`, `CENTER_STUDENTS`) |
| صور المدرّسة | `public/assets/hind-1.svg … hind-3.svg` (يمكن استبدالها بصور PNG/WebP بنفس الأسماء في CSS) |
| أرقام التواصل وروابط واتساب وفيسبوك | ابحث عن `201000000000` في `public/*.html` |

مثال لإضافة فيديو داخل درس: ضع داخل `segments` عنصرًا مثل
`{ "title": "المقطع الأول", "youtubeId": "ID11CHARS", "position": 1 }`.

## النشر على Vercel
```bash
npm i -g vercel
vercel --prod
```
للحفاظ على بيانات الطلاب بعد النشر فعّل تخزينًا دائمًا (Vercel Blob أو Upstash KV) — التفاصيل في `.env.example`. بدونه تُحفظ البيانات في ذاكرة مؤقتة فقط.
